YFM2 Tower — Auto-Start

Step-by-step on the tower PC. Do this once; after that the tower starts when you log in.

What this gives you: After you log into Windows, ~90 seconds later two windows open by themselves — YFM Tower API and Tailscale Funnel. You do not double-click anything each day.

Step 1 — Get the new files onto the tower

On your dev PC (Cursor laptop), copy these into Google Drive:

From: C:\Users\demalicperkins\yfm2\tower-server\

Copy these files → G:\My Drive\tower-server\

  • install-autostart.bat
  • start-tower-live-auto.bat
  • uninstall-autostart.bat
  • start-tower-live.bat (optional — for manual start)

Wait for Drive to sync to the tower (or copy via USB if Drive is slow).

Step 2 — Install auto-start (one time only)

  1. On the tower PC, open File Explorer.
  2. Go to G:\My Drive\tower-server
  3. Find install-autostart.bat
  4. Double-click it.
  5. If you see FAILED, right-click the file → Run as administrator → try again.
  6. When you see SUCCESS, press a key to close the window.

Step 3 — Test it

  1. Sign out of Windows on the tower, or restart the PC.
  2. Log back in.
  3. Wait about 90 seconds (Google Drive needs time to connect).
  4. You should see two cmd windows:
    • YFM Tower API — running python main.py
    • Tailscale Funnel — showing an https://… URL
  5. Leave both windows open all day while you use the site.

Step 4 — Check the tower is healthy

  1. On the tower, open a browser.
  2. Go to: http://localhost:8787/health
  3. You should see JSON with "ok": true and "apiVersion": "1.1.0".
If that works, the tower software is running. Copy the https URL from the Tailscale window into Vercel as VITE_TOWER_API_URL (only when the URL changes).

Step 5 — Use the website

  1. Open https://yfm2-theta.vercel.app
  2. Go to Eligibility
  3. Top right should say Tower online (green)
  4. For ZIP 24153: use Logged dropdown → pick 24153 → Run Qualifier

Want to remove auto-startDouble-click uninstall-autostart.bat
Important: The tower PC must stay on and logged in (not asleep at login screen) for jobs to run. Auto-start does not wake a shut-down PC.

Manual start (backup — no auto-start)

If you prefer to start by hand, double-click once per session:

G:\My Drive\tower-server\start-tower-live.bat

Or open two cmd windows:

cd /d "G:\My Drive\tower-server" then python main.py

tailscale funnel 8787
